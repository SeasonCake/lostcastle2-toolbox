## 已确认的过滤错误与 0.12.0

0.9.0–0.11.0 的所有 HP hook 在读取 HP 前都执行 `TryPlayer(owner)`，其中 `owner` 的静态类型是 `Creature`。interop 明确显示 `Player` 继承 `BaseInputPlayer`，不是 `Creature` 的派生类，所以该转换无法成立；所有合法玩家事件都会在观察入口被提前丢弃。

0.12.0 移除这个不可能成立的转换，改为验证：

```text
creature.OwnerPlayerIncludeMaster.OwnerCreature.EntityID == creature.EntityID
```

该关系已被既有伤害归属日志用于定位玩家根实体；实体 ID 同一性同时排除归属于玩家的召唤物。0.12.0 仍需自然启动和一组最短恢复正控，不能从静态修正直接宣称 runtime PASS。
