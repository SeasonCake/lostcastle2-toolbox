## 可见合同

这是日常操作型界面。信息顺序保持为：名称与启用状态 → 触发按键/修饰键/运行方式 → 高级限制 → 动作步骤 → 当前步骤编辑 → 保存与停止。

- 主按键和动作按键都增加“点击后直接按键”的录入方式；原下拉框保留，鼠标左/右/中键继续可从动作按键下拉框选取。
- 录入状态必须明确显示“等待按键”，成功后立即回显；不支持的键不得改写原值；再次点击录入按钮或移开焦点可安全取消。
- 录入期间不得触发现有宏；退出录入后须等物理按键释放再恢复监听。
- `BLOCKED_FOCUS` 是预期安全保护，显示为中性“安全暂停/请回游戏后重按”，不得使用执行错误的红色层级；真实执行异常仍保持红色。
- 新建及首次生成的默认宏最长运行60秒；“最长运行（秒）”移到默认可见区域并允许手动编辑。已有自定义配置按原值显示，不静默迁移。
- 提升辅助文字、下拉框和按钮的可读性，但不改变宏配置schema、既有方案、执行顺序、前台限定、最长时间或紧急停止合同。

## 验收矩阵

- 窗口：标准约980×820与最小780×680；100%、125%、150% DPI。
- 状态：默认、等待录入、有效键、无效键、取消/失焦、未保存、真实错误、非游戏前台安全暂停。
- 值：普通字母、数字、F键、Tab/Enter/Space、动作专用Esc/Back/方向/修饰键；动作鼠标键下拉回归。
- 展开：高级设置关闭/打开；两步与多步列表；长中文宏名。
- 保持：旧`macros.json`读写往返、三种触发模式、最长运行到时停止、紧急停止、下拉选键、步骤新增/替换/排序；新默认60秒，已有配置原值回显。

## Exclusions

- 不改变SendInput后端、游戏前台判定、宏时序、最长运行安全上限与配置schema。
- 不加入全局录键、任意字符扩展、鼠标钩子或新的后台权限。
- 本轮MOD增量收录作为独立数据/包形工作线处理，不与宏UI逻辑耦合。
