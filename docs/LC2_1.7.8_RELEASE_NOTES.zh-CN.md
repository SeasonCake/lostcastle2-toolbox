# 失落城堡2工具箱 1.7.8 群分享包

记录日期：2026-09-08。阶段：本地正式包制作与包后检查。
本包沿用1.7.7-r5恢复修订；1.7.7各候选继续保留为诊断内测历史。
群分享由作者执行，本次不包含GitHub Release发布。

## 本版变化

- 修复异常后永久停止接收战斗事件的问题。后台继续处理有效记录，连接断开时自动重连；
  无法恢复的过程数据保留缺口提示，不以错误记录污染统计。
- 增加Windows原生消息定时器，改善界面长时间不刷新的情况，并保留有界停顿诊断。
- 主窗口右上角提供“导出诊断”，可收集版本、运行环境、MOD状态、近期错误和当前快照。
- MOD安装支持完整原包、文件夹或DLL来源，改善长说明显示；目录新增多人背包与装备、尼娅召唤，
  更新狐狸剑姬组件、手掌与幽影配色、雷系流派增强方案等。
- 正式包使用Distribution档：不保存逐事件对局历史，不显示详细对局记录开关；
  故障参考样本和主动“导出诊断”保留。

## 验证依据

r5实际单人对局约18分19秒，10,236条事件序号连续，26次房间更新，没有数据缺口、坏记录或
队列丢弃；本轮297条健康记录中最大UI心跳间隔1.065秒，没有触发长停顿采样。
游戏官方结算事件、归档摘要、支持快照及全部事件离线回放的关键指标一致：
总伤害1,052,075、Boss伤害207,496、官方承伤384。

恢复机制另有坏行/Unicode/非有限值隔离、强制溢出/重连、跨局边界和并发导出检查。
原r1实战失败、r3的85.863秒心跳空档和r4短停顿采样继续保留，不倒推为已完整还原旧根因。
本次1.7.8仅升级版本标识与使用说明，统计、传输和界面恢复代码沿用已验证的r5。

## 使用与边界

完整解压后运行“失落城堡2工具箱.exe”，保留整个文件夹及`_internal`目录。
遇到异常时，点击右上角“导出诊断”，将ZIP和发生时间私发维护者。
MOD按需安装，不自动启用全部条目。雷系面板F9与其他部分功能有快捷键重叠。

单人本局验证不等于全部联机或MOD组合通过，也不代表每项回血/耗蓝都有独立游戏真值校准。
过程统计与最终结算口径可能不同；收到完整结算时按游戏官方值校正。
最终包身份、ZIP校验值和包后验证另记录在本地发布回执中。
