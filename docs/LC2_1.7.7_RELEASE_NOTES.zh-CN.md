# 失落城堡2工具箱 1.7.7 候选说明

更新日期：2026-09-08。版本生命周期：`diagnostic-internal`；r1 实测结果仍为 `runtime-failed`。1.7.7 各候选不公开发布，修复验证后从 1.7.8 开始正式发布。已完成的包后和5项完整可见检查保留原范围，不能覆盖实战失败；稳定下载仍为1.7.6。当前恢复工作见[恢复说明](LC2_1.7.7_RECOVERY.zh-CN.md)。

## 当前实测故障

原 r1 真实运行触发 `queue_overflow`，工具箱停止接受战斗事件，统计值和地图位置滞后于游戏。已保存运行进程主动导出的诊断与原截图。8组隔离条件中，7组未复现持续停滞，同字节突发正控复现了永久停收；最初GUI消费停滞的原因仍未确认，窗口采样只有时间相关证据。原局缺失历史不能补造。作者退出后自动监测已暂停，已选择恢复实施及 r2 后续诊断验证。

后继r5已完成本地构建、相称实际包/界面/管道检查并交付桌面诊断内测。它保留后台续收、坏行隔离、缺口提示，增加UI停顿采样和原生消息定时器；r3的85.863秒心跳空档仍保留原证据和因果限制。当前需要r5真实游戏反馈，不能把短时回放通过当成实机通过，详见恢复说明。

## 变化

- 主窗口右上角恢复“导出诊断”：游戏未启动时也可收集版本、运行环境、MOD文件情况、近期错误与当前状态，保存ZIP并显示位置。部分收集失败会明确标注；报告请私发维护者。
- MOD来源可选择对应版本的DLL、原始压缩包或解压目录；多文件条目要求完整来源，仍按登记大小和SHA-256核对。自带文件齐全时继续一键安装，已修改或未知的安装目标保留。
- 新增多人背包与装备1.0.17、尼娅召唤，更新召唤大师3.0相关组件、手掌与幽影配色1.11.0、雷系流派增强方案2.2.0。多人背包位于LC2增强计划之后。
- 修正紧凑窗口里长MOD说明的卡片高度与换行可用宽度，保持安装等操作按钮完整可见。
- Distribution仍不记录逐事件对局历史；支持诊断只包含可用支持信息和当前快照。工具箱为1.7.7，战斗Bridge与协议继续为已实测的1.7.4，本轮不更改数值算法。

完整目录变化见[源码说明](LC2_1.7.7_SOURCE_NOTES.zh-CN.md)。社区目录为62条目、64个功能文件，合计3,850,189字节。
