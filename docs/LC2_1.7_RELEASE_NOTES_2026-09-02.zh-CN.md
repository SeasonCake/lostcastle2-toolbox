# 失落城堡2工具箱 v1.7 发布说明

> lifecycle: `released / github-upload-readback-passed`

## 一句话介绍

v1.7 完成多人逐玩家实时伤害与官方结算核对，改进宏按键录入和社区 MOD 管理，并让全新游戏环境可由工具箱自动配置固定运行依赖。

## 主要变化

### 战斗统计

- Mini HUD 局中使用绿色“实时”，详细主界面使用“实时估算”并提示“结算可能校正”。
- 只有完整 SyncEnd 逐玩家值才显示“官方结算”；官方值会原样覆盖过程值，可能向上或向下校正。
- 多人逐槽、Boss、房间切换、离队与高延迟路径均按已验证的身份和统计口径处理；不使用倍率、取最大值或职业/武器/道具特判凑数。
- 正式版关闭高频逐事件、cache和终局验收探针日志；保留低频启动、连接与错误支持信号。

### 本地数据

- 正式版不默认生成逐事件 journal、partial、对局 ZIP 或测试归档。
- 当前局状态只保留在内存中，明确的新 session 会清空上一局状态，避免跨局累计和长期磁盘增长。
- 移除主窗口“手动导出”测试控件。

### 按键宏

- 主触发键和动作按键保留下拉选择，并支持点击“录入”后直接按键。
- 新建和首次生成的宏默认最长运行 60 秒，可在界面直接修改。
- 宏只在 `LostCastle2.exe` 为前台时发送输入；切出游戏、退出或修改配置会停止并释放按键。

### MOD 与运行环境

- 纳管 2 个原有工具与 56 个社区 MOD，共 57 个最小功能载荷；不会默认启用任何社区 MOD。
- 当前登记的社区载荷已由项目维护者确认可随免费公开工具箱正常分发；作者与来源仍按清单逐项保留。
- 全新且没有 BepInEx 的游戏环境，可由工具箱在首次启动游戏或安装 DLL MOD 时一次初始化固定 BepInEx 与只读 Combat Bridge。
- 检测到不同身份的现有 BepInEx 核心时停止，不盲目覆盖。

## 安装与升级

1. 下载正式 ZIP 并核对发布页提供的 SHA-256。
2. 关闭旧工具箱与游戏，把 ZIP 完整解压到一个新目录；不要直接在压缩包内运行，也不要混用不同版本的 `_internal`。
3. 保留旧目录用于回滚；如需沿用界面、宏或本地 MOD 设置，可备份旧目录中的 `config`。
4. 双击“失落城堡2工具箱.exe”。首次启动游戏时按提示初始化 HUD / MOD 运行环境。

## 已知边界

- Mini HUD 的“实时”表示经过多人实测核对的局中过程数据，不等于最终结算；只有完整 SyncEnd 才显示“官方结算”。
- 游戏更新可能改变 Hook 兼容性或统计口径；异常时请提供版本、复现步骤和界面现象，不要公开昵称、账号或未经筛选的完整日志。
- 真实 7–16 人联机、所有社区 MOD 组合以及未来游戏版本不作全部兼容保证。
