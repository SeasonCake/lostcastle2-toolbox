# 工具箱 B 站视频

视频已发布：[【失落城堡2】我做了个工具箱：实时数值监测＋一键MOD安装](https://www.bilibili.com/video/BV1oxb76JE64/)。演示版本为1.7.6；本页记录制作结果，不代表1.7.7二进制发布。

## 成片

最终精修版使用146秒、2560×1440、60fps结构，包含实战预览、赛博猫片头、实时监测、社区MOD、按键显示、宏操作、遭遇战、首领战和片尾。宏及战斗来自实际录制，HUD局部放大使用同一帧数据。

旁白使用平实的普通话男声，按语义缩短过长空白并重对齐字幕；保留实际游戏音效，配合原创轻电子器乐。最终优先封面为4:3、1920×1440。片尾交流群二维码随完整8秒自制片尾显示。

工具箱与实时监测介绍为自制；社区MOD保留各自作者，增强计划署名以演示面板和产品目录为准。
