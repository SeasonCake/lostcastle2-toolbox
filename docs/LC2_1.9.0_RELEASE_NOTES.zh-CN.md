# 失落城堡2工具箱 1.9.0 更新说明

2026-10-11，群分享包已完成本地交付，GitHub public-core 待上传回读。承伤、回复和法力计数优化继续留待后续。

## 本次变化

- 新增三个主要入口：队伍状态合并队友状态、背包和刻印；配装助手集中装备、武器附魔与已有灵魂石；LC 增强计划单独管理，保留茶橘柚、空容、刺心、木亦的原作者署名。
- 配装助手默认开启供查看，修改须手动确认并在营地进行；队伍状态默认关闭，增强计划默认不安装。工具箱自有的队伍状态和配装助手署名加菲_barista。
- 社区目录从72项增加至84项，本次新增12项、升级8项，共90个功能文件。升级动态血条、火龙、双刀、恶魔入侵、魔像盾、房间前缀、懒虫四合一与雷系强化；新增冰系、护甲、诅咒宝藏等增强及房间倒计时、救援、Boss演出和充能修正等可选功能。
- MOD 按战斗、信息、房间、掉落等用途分类，支持分类、搜索和安装状态共同筛选。状态扫描移到后台，减少列表定时刷新对按钮和搜索的影响。
- 主界面采用暖白、米灰和浅杏色，统一字体、按钮、圆角和表格间距。字号与 MOD 列宽跟随显示器缩放，也可独立调节；窄窗口的说明和操作自动分行。
- HUD 默认自动显示，新增队伍小窗开关与明确的盒子入口。队伍小窗可查看状态、背包和刻印，支持半透明、拖动和鼠标穿透锁定；主盒子仍用于完整管理和设置。
- 首页、MOD 页与左下角的“支持我们”均可直接悬停查看二维码；移入弹层后保持显示，移出后收起，点击可打开完整赞助目录。分享包仅保留一份微信二维码。
- 支持对已有不同 BepInEx 进行明确选定的更新，备份原运行环境并保留已有 MOD 和配置；安装、升级及卸载 DLL 前确认游戏已退出。未知、修改过或链接目标不作为登记旧文件清理。

密码保护的四个武器/角色包按作者决定暂不收录；旧版、重复输入和半成品不重复加入。所有社区 MOD 仍按需安装，不会自动全部启用。

## 使用

完整解压到新目录，运行失落城堡2工具箱.exe，并保留整个 `_internal` 文件夹。退出旧版后可复制旧包 `config` 目录保留盒子设置，不覆盖新版 `_internal`。

游戏目录中的 MOD 需要在对应条目执行更新，换工具箱不会自动更新全部插件。配装助手仅使用当前游戏目录与已有灵魂石；未同步的队友资源显示“未同步”。
