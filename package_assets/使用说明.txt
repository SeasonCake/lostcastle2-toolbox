失落城堡2工具箱 · 按键显示 / 按键宏 / 战斗统计 / MOD 管理 1.5.11

启动：双击“失落城堡2工具箱.exe”。
请保留整个“失落城堡2工具箱”文件夹，不要单独移动 EXE 或删除 `_internal` 目录。

常用操作：
- 拖动背景、标题、按键或底部空白区域移动窗口；纯净模式下也可直接拖动键帽。
- F8：完全隐藏/恢复；隐藏后不会出现在任务栏或 Alt-Tab。
- F9：开启/关闭鼠标穿透。
- F10：打开设置。
- F11：进入/退出纯净模式；只保留已选按键，隐藏背景和全部控件，不会自动开启鼠标穿透。
- 标题栏 T：金色为置顶，灰色为自由窗口。
- 齿轮：背景透明度、纯净模式、60%–180% 界面缩放、配色预设和显示键位。
- 普通模式右下角：拖动缩放角标直接改变窗口大小。
- 使用 Win+Shift+S 等截图工具切换前台后，程序会自动修复前景按键层与半透明背景层的顺序，无需点击窗口恢复。
- 自选键位会按“游戏核心键组 + 辅助键带”或物理键盘行自动排布。
- 启动游戏：通过 Steam 启动《失落城堡2》。
- 全新游戏环境首次点击“启动游戏”时，盒子会询问是否一键初始化 HUD / MOD 运行环境；只安装 BepInEx 与只读战斗 HUD Bridge，不会自动启用任何社区 MOD，调试控制台默认关闭。
- 设置页：可选择主窗口尺寸与字体档位，切换键盘/手柄显示，并分别调整按键悬浮窗和战斗 HUD 大小。

按键宏：
- 从右键菜单或显示设置底部打开“宏设置”。
- 内置单次连段、按住循环、开关循环三种示例，全部默认停用。
- 编辑触发键、模式、最长时间、循环间隔与动作步骤后，勾选“启用”并保存。
- 宏仅在 LostCastle2.exe 为当前前台窗口时发送；切出游戏、退出或修改配置会立即停止。
- Ctrl + Shift + F12：紧急停止全部宏并释放按键。

MOD 管理：
- 当前随包提供 2 个原有工具与 49 个按功能族去重的最新可用社区 MOD；实战/资源工具优先、外观类靠后，列表可按名称、作者和说明搜索。
- 选择 MOD 后可查看作者、用途和使用方法，再执行一键安装、启动游戏和精确卸载。
- 全新环境首次安装 DLL MOD 时也会先提示初始化；检测到不同版本的现有 BepInEx 核心时会停止，不会盲目覆盖。
- 把自己的 DLL、ZIP、7Z、RAR 或文件夹放入“用户MOD”，点击“添加 MOD”检查并编辑识别结果。
- 完整 lc2-mod.json 格式和可直接交给 AI 的提示词见“MOD自动添加说明.txt”。
- 主窗口左下角依次提供 GitHub、bilibili 和“投喂”；“投喂”悬停默认显示微信赞助码，点击打开“赞助与投喂”目录。工具箱因热爱《失落城堡2》而做；想支持加菲或催催更新时，可以自愿投喂猫罐头。

目录：
- config\settings.json：窗口、透明度、缩放、配色和键位设置。
- config\macros.json：宏方案；可随整个工具箱备份。
- config\managed_mods\：已配置的 MOD 本地副本。
- config\user_mods\：用户添加后的本地 MOD 登记与受管载荷。
- 用户MOD\：待自动识别的新 MOD 投放目录；原文件不会被自动删除。
- modules\：伤害桥接等后续扩展功能预留目录。
- exports\：后续对局数据或诊断导出预留目录。
- 赞助与投喂\：给加菲投喂猫罐头的自愿赞助说明与本地赞助码。
- 运行环境\：BepInEx/Bridge 初始化边界、版本来源和 BepInEx 许可证。
