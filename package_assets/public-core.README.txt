失落城堡2工具箱 1.9.0 · public-core 公开分享版

启动：双击“失落城堡2工具箱.exe”。请保留整个文件夹，不要单独移动 EXE 或删除 `_internal` 目录。

1.9.0更新：社区目录支持84项（12新增、8升级），新增队伍状态、LC增强计划和配装助手三个主入口，细化MOD功能分类；界面采用明亮暖白与鼠尾草绿配色，放大正文和按钮字号。配装助手默认可查看，修改须手动确认且仅在营地；队伍状态默认关闭，增强计划须自己提供原包后安装。随包仅一份微信码，支持我们完全自愿。承伤、回复和法力计数算法本版未改。

本包的边界：
- 包含工具箱本体、官方BepInEx build 785原始ZIP、项目自有LC2 Combat Bridge 1.7.4和队伍/配装功能组件1.9.0，以及带完整许可证的7-Zip命令行组件。
- 不包含灵魂石修改器、金币编辑器 DLL，也不包含任何社区 MOD DLL、资源载荷、来源压缩包、游戏日志、截图、用户配置或历史对局导出。
- MOD 列表仍会显示可识别项目，但全部是“用户自行提供原包”模式。安装时需选择自己取得的文件、压缩包或解压目录；工具箱会按登记的文件大小和 SHA-256 校验，不会联网代下 MOD。

首次运行与目录：
- 首次游戏启动需要联网获取或生成Unity兼容文件。本轮未验证真实public-core首次游戏启动及其下载链路；游戏效果和全部联机/MOD组合也未逐一实测。
- `config` 初始为空，用于本机窗口、宏和受管 MOD 设置。
- `用户MOD` 用于放入自己取得的 DLL、ZIP、7Z、RAR 或文件夹。
- 正式分享档不启用逐事件对局归档。主窗口右上角提供“导出诊断”，收集版本、运行环境、MOD 文件情况、近期错误与当前统计快照；没启动游戏也能使用，不包含此前未记录的逐事件历史。
- 诊断 ZIP 保存到 Windows 文档目录下的“失落城堡2工具箱\诊断”，完成后可打开所在文件夹。请私发维护者并说明出错步骤；部分信息无法读取时报告会明确标注。
- `config\support` 保留有限大小的启动、操作和错误记录，不记录全局按键。
- `运行环境\public-core` 保存 BepInEx 及其精确构建依赖的许可证和来源说明。
- `赞助与投喂` 是自愿赞助素材，不影响任何功能。
- 已有BepInEx需要更新时先备份并保留插件/配置；请完全退出游戏后操作。框架更新失败会恢复原文件，启动时自行处理的Unity兼容DLL不会反复触发框架更新。
- 队伍与配装组件只在本机保存当前状态。队友未同步的资源显示“未同步”；切换角色、离开营地或数据过期时不执行配装请求。

战斗统计口径：
- Mini HUD局中逐玩家与团队数值标为“实时”；详细页说明“实时估算/结算可能校正”，过程值可能与稍后的游戏结算不同。
- 多人 SyncEnd 或单人结算UI的逐玩家记录通过身份门后才标为“官方结算”，并以造成伤害、Boss伤害和承伤最终值原样覆盖估算；修正可能向上，也可能向下。
- 结算record暂不可用时，可信单人结算UI仍会结束当前估算session，避免下一局继承旧活动状态；不会伪造官方值或写入对局归档。
